# Bookshop Landing Page

## Overview
- Task: Landing Page (Task 1)
- Brand: Page Turner Bookshop & Creative Corner

## Preview
![Landing Page Preview](Screenshot-index.png)

## Tech Stack
- HTML5
- CSS3 (Flexbox & Media Queries)
- Google Fonts (Montserrat & Inter)

## Features
- Sticky navbar with book logo icon
- Responsive CSS hamburger menu for mobile screens
- Full-screen hero section (`100vh`) with background image
- Book categories section (Fiction, Non-Fiction, Fantasy, Children's)
- Creative items section (Leather Journals, Bookmarks, Reading Lights)
- Pricing in INR (₹99 - ₹4,000)
- About section (Founded 2026)
- Footer with Kerala address and contact info
- Responsive layout for mobile devices

- `index.html` - Page structure
